# AI-анализ CRM-кейсов в n8n

Демонстрационный прототип для тестового задания: помогает support-сотруднику сравнить факты из CRM и рабочей переписки, увидеть расхождения и получить рекомендуемый следующий шаг.

## Что находится в репозитории

- `workflow/workflow.json` — экспорт workflow из n8n для просмотра или импорта.
- `deliverables/Итоговое_тестовое_задание.pdf` — итоговый документ.
- `deliverables/Итоговое_тестовое_задание.md` — исходный текст документа.
- `deliverables/Письмо_для_отправки.md` — подготовленный текст письма.
- `source/исходное_задание.pdf` — исходное тестовое задание.

## Запуск демонстрации

Workflow находится в n8n по адресу: https://step123.app.n8n.cloud/workflow/SVMjRg6p4Wst1Uw2

Он запускается вручную на четырёх примерах из задания. Для запуска требуется настроить собственный OpenAI credential в n8n. К рабочей CRM и чатам workflow не подключён и не активирован. Автоматические изменения CRM и отправка сообщений не выполняются.

При переносе workflow в другой n8n-инстанс импортируйте JSON-файл и настройте необходимое подключение модели в самом n8n. Секретные ключи в репозиторий не включены.

## Границы прототипа

Приоритеты — предварительные правила для примеров тестового задания и требуют подтверждения владельцем процесса. Результат проверяет человек. Подключения к реальным источникам и пилот с сотрудниками не проводились.
